# v0.1.0-dev — 开发预览 / Development preview

这是 WeCom Agent Bridge 的首个开发预览版本，供源码阅读、独立测试部署和反馈使用。请将 GitHub Release 标记为 **Pre-release**，不作为稳定生产版本推荐。

## 本次提供

- Cloudflare Workers + D1：企业微信加密回调、持久化收件箱、显式 ACK 和重复回调去重。
- 腾讯 SCF：文本、图片、文件发送，素材接口及微信客服同步接口。
- Python 参考客户端：媒体校验、断点恢复、客服 SQLite 状态与机器人附件过期处理。
- 中英文 README、部署指南、API 约定、已知限制、贡献说明和 Apache-2.0 许可证。
- 仅运行测试的 CI；不包含生产凭证、可用生产资源绑定或自动部署工作流。

## 已验证范围

目前实际接通的智能体平台是 Muse（https://muse.ai/join）。文本双向通信、图片收发和微信客服文件接收已在作者原有私有部署验证。其他智能体平台尚未进行实际接入验收。

本开发基线的本地验证包括 193 项 Worker 检查、87 项 Python 测试及 Worker 打包检查；功能基线及 README 更新的 GitHub Python/Worker CI 均已通过。这些结果不替代开源版本在全新云资源上的端到端验收。

## 已知限制

- 机器人 URL 回调及附件能力仍属实验功能；短期签名链接可能过期。
- 机器人附件当前每取一块都会重新完整下载，客户端和 Worker 的超时预算尚需协调。
- 至少一次交付，面向单个逻辑消费者；下游任务需要自行持久化去重与互斥。
- 客服 SQLite 绑定服务 URL，更换域名需要保留状态并设计显式迁移。
- 尚未提供自动保留清理、积压告警或数据库健康探测。

详见 [已知限制](https://github.com/itestgroup/wecom-agent-bridge/blob/v0.1.0-dev/docs/limitations.md) 和 [部署指南](https://github.com/itestgroup/wecom-agent-bridge/blob/v0.1.0-dev/docs/deployment.md)。请使用自己的独立测试资源，不要直接复用其他部署的数据和凭证。

此项目独立演进，不会自动同步、合并或部署到作者的私有生产仓库。

## English

First development preview of a self-hosted WeCom–AI agent bridge. Includes Workers/D1 callback receipts and ACK, SCF outbound/media/customer-service APIs, Python clients, and Apache-2.0 licensing. Muse is the platform verified in the author's original private deployment; fresh-resource end-to-end acceptance of this independent baseline remains pending. Bot attachments remain experimental. Delivery is at least once: consumers must implement durable task deduplication. Test CI does not deploy cloud services. Mark this release as a **Pre-release**.
